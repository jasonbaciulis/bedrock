Push the current branch, create a pull request to main, and create a new release.

1. Run `git log main..HEAD --oneline` to see what commits are on this branch.
2. Run `git diff main...HEAD --stat` to see changed files.
3. Push the current branch: `git push -u origin HEAD`
4. Create a PR to main using `gh pr create --base main`. Write a concise title (under 70 characters) and a short description summarizing the changes. Use this format for the body:

```
## What's new
<bullet points>

## What's fixed
<bullet points>
```

Don't include anything else. Don't mention it's generated by Claude.

5. Return the PR URL.

6. Determine the current release version by running `gh release list --limit 1` (or `git tag --sort=-v:refname | head -1`). The latest tag looks like `vX.Y.Z`.
7. Ask me whether this should be a **major**, **minor**, or **patch** release, then bump the version accordingly:
   - **major**: bump X, reset Y and Z to 0 (e.g. `2.0.0` → `3.0.0`)
   - **minor**: bump Y, reset Z to 0 (e.g. `2.0.0` → `2.1.0`)
   - **patch**: bump Z (e.g. `2.0.0` → `2.0.1`)
8. Create the release with `gh release create vX.Y.Z --target main --title "vX.Y.Z"`, using the new version. Use the same body format as the PR:

```
## What's new
<bullet points>

## What's fixed
<bullet points>
```

9. Return the release URL.
